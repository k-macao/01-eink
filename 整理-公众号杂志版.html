项目总览与阅读动线

 用一套 Python 流水线完成「采集 → 分析 → 生成 → 新鲜度检查 → 推送」，默认采用 lime 白底圆角卡片 + 荧光绿强调风（可切换 pixel / forum / dossier / guizang）。

02 QUANT ENGINE

量化与策略引擎

 从单指标趋势到多流派评审团，从五维概念轮动到 31 个申万行业，每套算法均明确写出触发条件、样本门槛与失效边界。
6+ MODELS

多引擎协同与软压缩防爆表

 所有因子均经过 2·tanh(x/2) 软压缩（cap=2）与样本量门禁，避免单因子极端值绑架总分。
序号 引擎模块 算法口径与评分机制 防自欺与风控门禁

03 MACD 四项派生信号 柱体收敛（连缩 ≥3 根且幅度 ≥25%）、确认底背离（5 日分形枢轴）、布林回归（触下轨后收回到带内 + 柱回升）、周日共振（≥35 周 + 日金叉） 左侧信号未过零轴必须标「左侧试探」；残缺当前周排除，防止盘中伪共振
04 因子软压缩（tanh cap） 显示值 = 2·tanh(原始值/2)，cap=2；小信号（≤0.5）保留 ≥98%，极端值（≥4）削去 >50% 单因子最高权重 30%（MOM），极端原始值最多贡献 ±0.60，防止单因子绑架总分
05 Jev 本地研判层（可选） TypeSafe 的 System One：砍掉自由文本生成，只输出 choice（方向）、score（风险档位）、noul（收涨概率）三类原语 只需 onnxruntime + tokenizers + numpy；复用 5%~95% 概率夹边与 ±20pp 偏离收敛护栏
