## 二、指标口径（全部本地纯 Python，无新依赖）

| 指标 | 公式 / 规则 | 边界 |
|---|---|---|
| 5 / 20 / 60 日收益 | `close[-1] / close[-1-n] − 1` | 日线不足该窗口 → 该指标显「—」，不推算 |
| 年化波动 | 近 20 个日收益的样本标准差 × √252 × 100 | 样本 <2 → 空值 |
| 夏普（20 日） | `mean(日收益) / std(日收益) × √252`（无风险利率按 0） | 标准差 0 或样本 <5 → 空值 |
| 最大回撤（60 日） | 近 60 根收盘的滚动峰值回撤最小值 | 单边上涨 → 0.0% |
| 胜率（20 日） | 近 20 个日收益中 >0 的占比 | 无样本 → 空值 |
| MA20 / MA60 | 最近 N 根收盘均值 | 样本不足 → 空值 |
| 趋势 | 收盘 > MA20 > MA60 → 多头排列；收盘 < MA20 < MA60 → 空头排列；否则偏多 / 偏空震荡 | 任一均线缺失 → 「数据不足」 |
| 信号分 | `clip(30, ret20×3) + clip(20, ret60×1.2)`，多头排列 +15 / 空头排列 −15 / 偏多 +6 / 偏空 −6，高波动（分位 >70）乘 0.8，最终夹在 −100~+100 | **只用于大类内排序**，不是涨跌概率，不含交易成本 |
| 大类 | 细分 20/60 日收益与信号分的算术均值；趋势一致则沿用，分歧则标「分化」 | 大类不跨类加权 |
| 市场状态 | 按权益 / 纯债 / CTA 三类信号均值判定：权益占优 / 避险·债占优 / 商品·CTA占优 / 普跌承压 / 分化轮动 / 均衡 | 可用大类 <2 时写「数据不足」 |

## 四、审计与门禁

| 项 | 处理 |
|---|---|
| 数据覆盖 | `策略量化` 作为一条独立来源计入总源数；取不到时归入「暂缺」点名 |
| 当天检验 | `is_today=False`（已收盘回看，不是「今天发布的内容」），**不会**单独把日报推过门禁，也不虚增当天源 |
| 失败隔离 | 取数 / 计算 / 渲染各自 try：单栏异常只影响该栏，绝不拖垮整份日报 |
| 关闭方式 | `OCTOPUS_STRATEGY_QUANT=0` → 不采集、不渲染、不进审计（总源数回落，与关闭前一致） |
