3.1 量化引擎分层

#模块职责
01providersYahoo / 东方财富日与周 K、成交、资金流等数据
02macd_strategy市场库 / 已有日线 / 免费源编排、历史补足、MACD 交叉与零轴过滤
03macd_derivatives连续柱体极值预警、确认底背离、布林回归、已定稿周日共振
04featuresMOM、TRD、REV、VOL、FLOW 五因子与趋势特征
05probability历史滚动重算、分桶、保序回归（PAVA）、逻辑回归校准
06liquidity南北向成交、量能、Amihud 非流动性、CR5 / CR20 集中度及综合分
07engine编排计算、推进式回测、预测留痕与后续结算
08render结果渲染为 HTML，由流水线注入主题排版
#阶段处理结果
01① collect收集指数 / 个股日线、沪深港通成交与港股成交数据标准化数据序列
02② features逐日计算五因子；每个时点只使用当时可得数据因子分数与特征
03③ probability用历史样本校准概率，并进行滚动检验概率、区间与回测指标
04④ liquidity计算成交量、资金流与市场深度流动性画像及有界概率修正
05⑤ validate推进式回测；预测写入记录并于之后结算命中率、Brier 与预测复盘
06⑥ decide综合概率、区间和趋势状态一句话预测概括

3.3 MACD 策略

条目组分组标题
◆

基础规则

#项目基础规则
01计算公式DIF = EMA12 − EMA26；DEA = EMA9(DIF)；页面使用国内双倍柱 MACD = 2 × (DIF − DEA)
02最低样本至少 36 根有效已收盘日线
03金叉金叉且 DIF、DEA 都在零轴上方 → 下一交易日观察入场
04持有多头排列且双线在零轴上方 → 持有
05退出 / 规避死叉或空头排列 → 退出 / 规避
06水下金叉零轴下方金叉只观察反弹
条目组分组标题
◆

派生策略

#分支默认确定性口径作用 / 限制
01连续柱体收敛连续 3 次同侧收敛；起点 H/价在此前最多 60 个柱体的 P10/P90动能预警，不是确定底部
02确认底背离最多 120 根、至少 45 根有效最低价；价格 / DIF 谷左右各 2 根，±3 根匹配价格谷后第 5 根才定稿，不回填最低点
03布林回归BB(20,2)，冻结前一日带，触下轨后收回轨内 + 动能修复 + 中轨平缓过滤研究性震荡代理；强趋势沿上轨不自动卖
04周日共振至少 35 个已结束周，周 DIF>DEA + 日金叉；仍需日双线水上才算顺势确认日金叉与柱翻红为同一事件；残缺当前周排除

7.6 内容口径标记

#页面标记含义
01当天来源内容日期与报告日一致
02非当天 / 滞后内容日期早于报告日，页面标出日期；滞后报价不计入核心指数均值
03今日抓取今天采集到的前瞻日历快照，不代表事件今天已发生
04暂缺 / 未展示来源或对应数据块没有可用内容
05概率与回测根据历史数据或明确规则得到的统计结果
06AI 研判 / AI帮你提鲜基于本次页面数据规则合成的辅助说明
07↳ 同子栏合并同一批数据只在第一个（或口径更专业的）栏目展开，后出现的栏目保留子栏标题 + 一行指针；数字不静默消失，结论三栏仍复述关键数字（详见《大纲-栏目重复率核对.md》）
编号 页脚项目 详细说明
01 生成来源 由 整理.md 自动经 tools/render_table_report.py 渲染生成
02 运行依赖 内嵌样式，无外部字体、脚本或网络依赖；所有内容均以多行多列表格呈现
