## 二、根因：为什么上线以来 18 家一直 0 条

| # | 根因 | 机制 | 证据 |
|---:|---|---|---|
| 01 | **平台跳转链接被白名单整条拒绝** | Bing News RSS 的 `<link>` 是 `http://www.bing.com/news/apiclick.aspx?…&url=https%3a%2f%2fwww.cs.com.cn%2f…`：① 明文 `http`；② 主机是 `www.bing.com` 而不是媒体域名。`_news_url()` 两条都不过 → 该条目标记为「无可用链接」丢弃 | 探针 JSON 里 `原文链接形态` 一列，14 个有结果的域名**全部**是这一形态（系统性，不是个别媒体） |
| 02 | **候选源「解析成功就停」** | 旧逻辑只要第一路候选源解析出条目就 `break`，不管这些条目最后有没有通过窗口 / 白名单校验 → 停在 Bing 上永远 0 条，后面真正能用的 Google News 根本轮不到 | 新测试 `test_unusable_first_candidate_falls_through_to_the_next`（`tests/test_mainland_news.py`）用 mock 断言：第一路 0 条可用 → 第二路被调用 |
| 03 | **凤凰网财经 `site:` 域过宽** | `site:ifeng.com` 会把汽车、娱乐、体育全捞进来（实测 12 条里混进大量非财经），收紧为 `finance.ifeng.com` 后 12 条全为财经（A股午评、证监会、中欧电动车磋商等） | 两次实测对比，见「外部核验记录」 |
| 04 | **IT之家走检索导致滞后** | 检索源最新条目比官网 RSS 晚约 11 小时 | 官方 feed 实测 13 日 12:29 vs 检索源当日凌晨 |

### 5.4.3 预警趋势与今日风险态势口径（2026-10-20 新增，「平时也有功能」）

用户要求「AI 预警风险点，平时也有功能，分析预警」，经确认两件都做：**历史对比预警趋势** +
**平时态势分析行**。目标：0 命中的安静日不再只有一句「未命中风险词表」，而是天天都有基于存档的
对比分析与确定性结论；有命中的日子则多一个「比最近存档日是升级还是解除」的维度。

| 维度 | 规则 |
|---|---|
| 趋势数据源 | `output/news_history.json` 存档（每日采集后追加、从不改写）里 `section=内地财经媒体` 的条目，按条目自身 `date`（缺则取 `ts` 日期，再缺按采集日）分片；其他栏目存档不混入（测试 `test_corpus_only_counts_mainland_section` 守着） |
| 重算口径 | 最近 7 个自然日逐日重算**同一份**风险词表（`daily_risk_profile`：标题级命中、五类、条数/媒体数、传播度等级），等级规则与当日 72 小时窗口榜完全一致；页面明示「存档日期口径」，不与窗口口径混写 |
| 对比基准 | 今日切片 vs **最近存档日**（`baseline_date`，通常 = 昨天）：每类给 新增 / 升级 / 持续 / 降级 / 解除 之一（等级序 高＞中＞关注），全量版另附逐日命中数与各类变化明细 |
| 措辞纪律 | 同一结果两版措辞：`trend_phrase`（「较最近存档日 升级 1 类、…」）给栏目趋势行与态势行，`trend_brief`（「按日对比 升级 1、…」）给「🦑 AI帮你提鲜」——同栏不同句，`tools/report_outline.py` 栏内重复保持 0（测试 `test_note_and_ren_consume_same_result` 守着） |
| 今日风险态势 | 天天一行确定性结论（`risk_posture`）：情绪面定调前缀 + ≤13 字定论——0 命中非偏空「无预警命中，保持观察」/ 0 命中偏空「无预警命中，留意报道」/ 有高「有【高】级预警，优先核证据」/ 有中「有【中】级预警，关注传播面」/ 仅关注「仅关注级命中，保持观察」；全量版再缀趋势短语。**0 命中披露行保留不动**，态势行是补充不是替代（测试 `test_zero_hit_day_keeps_disclosure_and_gains_posture` 守着） |
| 诚实边界 | 存档不足 → 趋势行整行不出 + 态势写「历史存档不足，暂不按日对比」；今日存档 <5 条 → `low_sample` 如实提示「样本尚少，对比仅作提示」；趋势是词典启发式的按日对比，不是预测，不包装成概率；⌁ AI 研判行**不带**趋势句（研判维持情绪合成口径，避免同栏三处同句） |
| 确定性 | `analyze_risk_trend` / `risk_posture` 是纯函数：同一份存档两次跑出同一份结果（测试 `test_build_with_corpus_is_deterministic` 与 `RiskTrendPostureTests` 逐字段断言） |
