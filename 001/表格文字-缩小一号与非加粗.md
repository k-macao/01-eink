# 表格内文字：缩小一号 + 一律不加粗（2026-10-23）

用户要求原话：**「表格内文字，缩小一号，然后非加粗」**。

落地口径：日报里所有**内容表格**（数据表 / KV 表 / 资讯列表表 / AI 结论表 / 诗选卡）的表格内文字，
字号各收 1px，字重统一 400；**版面装饰**（刊头、栏目标题、徽标胶囊、正文段落、八卦卡）不动。
五套主题（lime / guizang / dossier / forum / pixel）同步生效，无新增开关、无新增定时任务。

## 为什么只能改内联样式

微信 / PushPlus 的 `v-html` 清洗会丢掉 `<style>` 块，只保留标签上的内联 `style`，
所以不能用一条 `td { font-weight:400 }` 的 CSS 规则统一处理。本仓一贯的做法是把样式写在标签上，
这次同样在**表格渲染器这一层**改，并且额外处理单元格内容里的粗体标记：

- `output/pipeline.py:_table_text()` —— `<b>` / `<strong>` 降级成 `<span>`（颜色、字号、字距等属性原样保留），
  内联 `font-weight:600/700/800/900/bold/bolder` 改写为 `font-weight:400`；`<br>`、`<span>` 等不受影响。
- `output/strategy_quant.py:_plain_cell()` —— 兜底渲染路径（kit 缺失时）的同口径实现。
- 表级样式同时写 `font-weight:400`，保证未显式标注字重的继承文字也是常规字重。

## 字号对照

| 渲染器 | 用途 | 原 | 新 |
|---|---|---|---|
| `GZ_FS_TABLE` | lime / guizang / dossier / forum 的数据表、KV 表、资讯卡、栏目行内容外壳 | 13px | **12px** |
| `_ren_judgment_row` | 各栏目「AI帮你提鲜」结论表（表头 / 结论标签 / 结论文字 / 概率数字 / 几率条） | 13 / 11 / 12 / 17 / 13px | **12 / 10 / 11 / 16 / 12px** |
| `_pixel_table` | pixel 数据表（表头 / 表身） | 10 / 11px | **9 / 10px** |
| `_ledger_table`（`_data_table` / `_mini_table`） | pixel 账本式双列表（行情 / KV） | 12px | **11px** |
| `_quote_value` | pixel 账本表内的报价数值 | 13px | **12px** |
| `_item_row` | pixel 资讯行（序号 / 正文） | 11 / 12px | **10 / 11px** |
| `shiquan_poem.render_opening_poem_html` | 诗选卡（诗题 / 诗句 / 左栏标签 / 徽标），五主题 | 15 / 14 / 11~12 / 10px | **14 / 13 / 10~11 / 9px** |
| `strategy_quant._kit_table` / `_kit_kv` | kit 缺失时的兜底表 | 12px | **11px** |

字重：以上表格内**全部 400**（原来分别是 600 / 700 / 800 / 900 或 `<b>` 标签）。
`GZ_FS_TABLE=12` 仍高于字号下限 `GZ_FS_FLOOR=11`，也仍小于正文 `GZ_FS_BODY=14`，阶梯关系不变。

## 明确不改的部分

| 对象 | 原因 |
|---|---|
| 刊头（26px / 900）、栏目标题 `<h2>`（18px / 700~900）、栏目编号 kicker | 属于字号阶梯的标题层，不是表格内文字 |
| 徽标 / 胶囊（`今日抓取`、`LIVE`、`■` 色块等） | 徽标自身口径不变；但**落在表格单元格里时随表格去粗** |
| 正文段落、`gz_subsection` 子标题、斑马纹正文块（`_gz_zebra_bands`） | 它们是段落文字，只是为兼容微信套了单列表格外壳 |
| 八卦卡（`output/octopus_bagua.py`：卦画 + 卦辞） | 属于版面卡片（图形列 + 文字列），不是数据表；如需要一起收，说一声即可 |
| pixel 终端窗口框、`_pixel_panel` / `_alert`、分条横幅、页脚 | 版面装饰 |
| 历史日报 HTML | 沿用仓库约定不自动改写；下一次采集运行起生效 |

## 验证

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_table_typography.py'
.venv/bin/python -m unittest discover -s tests -p 'test_pipeline.py'
```

- `tests/test_table_typography.py` 22 项：字号阶梯常量、`_table_text` / `_plain_cell` 去粗规则
  （含 `<br>` 不被误伤、颜色保留、600~900 全覆盖）、各表格渲染器内联样式、诗选卡五主题、
  兜底表，以及整页回归（四套归藏系主题的数据表体内不得出现 `<b>`/`<strong>`/600~900 字重，
  同时刊头 26px 与栏目标题字重保持不变）。
- 全库回归 1127 项：5 失败 1 跳过；这 5 项在未修改的 HEAD 基线上同一时刻逐条复现同样失败
  （旧行业轮动 / 新闻时间门禁 / 旧量化结论标签），与本次改动无关。
