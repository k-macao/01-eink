### 4.1 合并规则（写成代码常量，见 `output/pipeline.py` 顶部模块说明第 26 条与 SUB_MERGE 常量段）

| # | 规则 | 为什么 |
|---:|---|---|
| 1 | 同一批数据只展开一次：后出现的栏目**保留子栏标题**，内容改为一行指针 `↳ 同子栏合并 · （口径）｜见 XX 栏目（同一批数据，不重复展示）` | 数字不静默消失：读者知道去哪儿看，也不会以为漏抓 |
| 2 | 指针指**栏目名**（不带序号） | 栏目序号按当日实际出场栏数动态编号，写死序号会在缺栏那天指错栏目 |

## 五、未合并项与逐条理由

| 重复现象 | 实测 | 处置与理由 |
|---|---|---|
| 结论三栏复述正文数字 | 16 → 03 100%；17 → 12 71%；18 → 06 36% / → 12 29% / → 03 21% | **不合并**：总结 / 今日预判 / 短线速查卡的设计目标就是「一屏读完结论 + 动作」；数字与正文同源（不是另算一套），删掉会失去收尾 |
| 03 量化分析总览的「预测概括」行复述 | 与 04（恒指波动分位 29%）、05（流动性综合分 22/100）、16（33% / 51% / 52%）共有 | **不合并**：这是栏目内的**概括行**（总览口径），删掉会让「量化分析总览」失去总览性；且 04 的 29% 是「指数趋势与波动」里恒指的波动分位，两处口径相同、数值同源，属于「同一数字在总览与被总览栏各一次」，保留便于对照 |
| 03 ⇄ 04 的 33% 事实重复 | 逐行核对：**29% 是同一个数据点**（03「波动率 29% 分位」= 04 恒指「波动分位 29%」）；**33% / 45% / 53% / 54% 是巧合同值**——03「模型可信度 5 日基准 45%」vs 04 安踏「20 日 45%」、03 恒指「5 日 54%」vs 04 安踏「5 日 54%」、03「预测复盘命中 33%」vs 04「近 20 日上涨 33%」 | **不合并**：不是同一批数据，只是数字相同。这条也说明「数字指纹重复率」只能当线索，合并决定必须以逐行核对为准；唯一的同源项（恒指波动分位）保留在两栏各一次，因为它是 03 概括行对 04 明细的引用 |
| 恒指现价 24,271.20 出现在 03 / 06 / 12 | 03 指数概率、06 锚定 10-12 收盘、12 港股双指数 | **不合并**：三处都是「锚」，各自服务于概率、逐日路径、行情复盘；且是同一个数字的同一口径（13 栏的 24,211.35 是**滞后行情日 10-09**，两栏都带日期标记，不构成重复） |
| 港股个股在 04 与 13 各出现一次 | 共有标的 0388 / 0700 / 0941 / 1810 | **不合并**：口径不同——04 是概率池（现价 + 5/20 日概率 + 量比 + 主力净额，行情日 10-12），13 是境外行情明细（价 / 涨跌 / 成交量 / 供数来源，行情日滞后）。合并会混淆「当天 / 滞后」标记 |
| 社区样本在 00 与 14 各出现一次 | 共有 1,407 / 14,416（StockTwits 关注人数） | **暂不合并**：00 是因子计数（关注数 + 多空标签 + NBI 口径），14 是平台榜单明细（标题 / 摘要 / 时间）。若要去掉，最稳是「关注人数只留 00、14 的榜只留标题与摘要」——需要你确认，默认保留 |
| 02 UZI 与 01 MACD 用同一批 6 指数日线 | 共有 000001 / 399001 / 5.6% 等 | **不合并**：指标集不同（MACD 的 DIF / DEA / 柱 vs Weinstein 阶段 / 均线 / RSI / KDJ / WR / 位置）；两栏分别服务「策略」与「规则引擎趋势」，跨栏共用同一批日线（零新增联网）本身是设计 |
| 各栏末尾「AI帮你提鲜」的几率条复述本栏概率 | 栏内现象 | **不合并**：2026-10-06 按用户要求新增的独立内容区（大白话 + 几率条），定位是「翻译」；口径与正文同源并已在栏目说明里标注 |
| 01 ⇄ 12 之外，正文栏再无子栏级重复 | 重复子栏清单只有 1 条（已合并） | 保持现状：核对脚本可随时复跑，出现新重复会立刻暴露 |
